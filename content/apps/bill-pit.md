# Bill Pit

Gestão inteligente de despesas recorrentes e únicas com calendário visual, notificações inteligentes e backup automático.

## Features

- **Gestão de despesas**: Recorrentes e únicas, com valores variáveis por mês
- **Calendário visual**: Visualiza as tuas despesas num calendário mensal
- **Notificações inteligentes**: Resumos mensais, alertas de atraso e verificação de valores
- **Backup automático**: Backup diário no telemóvel + partilha/exportação
- **Categorias personalizáveis**: Organiza as tuas despesas por categorias
- **Tutorial integrado**: Onboarding interativo para novos utilizadores

## Como funciona

1. **Adiciona as tuas despesas** — recorrentes (mensal, bimestral, trimestral, semestral, anual) ou únicas
2. **Define valores variáveis** — para despesas que mudam de mês para mês (ex: electricidade)
3. **Acompanha no calendário** — vê tudo num só sítio
4. **Recebe alertas** — nunca mais te esqueces de uma despesa

## Stack técnica

- Flutter 3.44
- Isar Database (offline-first)
- Provider (state management)
- Workmanager (notificações background)
- fl_chart (gráficos)

## Privacidade

- **100% offline** — os teus dados nunca saem do telemóvel
- Sem contas, sem login, sem tracking
- Backup local e partilha peer-to-peer
